# Packaged Inter

Unmodified static Inter4.1 Regular400, SemiBold600 and Bold700 from the author's official release:
https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

Licensed SIL Open Font License1.1; original license is packaged in assets/licenses/Inter-OFL.txt.
All fonts ship offline in res/font; there is no downloadable-font provider, network dependency or device font substitution in the normal path.
